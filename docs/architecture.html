Coding-agent OpenTelemetry Collector — clients, flows, and code structure

Custom Collector distribution (otelcol-coding-agents, OCB-pinned) that normalizes coding-agent telemetry into a canonical trace per user turn while exporting raw vendor telemetry in parallel. Source of truth: builder-config.yaml, collector-config.yaml, docs/design.md.

End-to-end flow through the Collector

Code and class structure

One component type with two connector edges (logs→traces, traces→traces), each a router over per-harness packages. The module layout mirrors opentelemetry-collector-contrib: public Collector surface at the module root, harness logic in internal packages so schemas stay out of the public API. A harness package may use nothing from another harness package except its Claimer (enforced by TestNoCrossHarnessImports).

connector/codingagentconnector component root

Public Collector surface (own Go module, built into the distribution via OCB)

  • NewFactory — factory.go; registers the logs→traces and traces→traces edges (connector.NewFactory), default config, stability from generated metadata.
  • Config — config.go; the connector-wide capture_identity plus one block per harness (codex:, cursor:, claude_code:), so the YAML tree and the Go type tree match. Validate wraps each block's error with its key. codex.signals (default [logs]) chooses between Codex's two implementations; claude_code.chat_source (traces | logs) chooses which Claude Code signal emits chat spans.
  • logsRouter — logs.go; fans each logs batch to codex (only when signals include logs), cursor, and claudelogs. Claims are disjoint (codex.* event names, cursor.telemetry scope, claude_code.events api_request/api_error), so a record lands in at most one edge. Start/Shutdown fan out because codex and cursor own sweep loops and drain state.
  • tracesRouter — traces.go; fans each traces batch to claude, genai, opencode, pi, openhands, and codextraces (only when signals include traces). The GenAI edge skips any group that the claude, opencode, pi, or openhands Claimer owns; codextraces claims scope == service.name groups, which no GenAI prefix can equal. A group is emitted at most once.
  • internal/metadata — mdatagen-generated status and TelemetryBuilder (self-metrics wiring).

internal/canonical + internal/content shared

The closed canonical vocabulary every edge writes into

  • canonical.Claimer (claim.go) — Claim(ptrace.ResourceSpans) bool. Exported as Claimer by claude, opencode, pi, openhands, and codextraces; the only identifier one harness package may import from another.
  • vocabulary.go / resource.go — span-attribute and resource-key allowlists. FilterResource strips everything outside the contract (and host.name when capture_identity is false).
  • conformance.go — declares each source-backed pairing of a native attribute with its canonical counterpart; every edge wired in traces.go/logs.go must have an entry in conformance_test.go or CI fails.
  • content.Strip — reduces a span to the attribute allowlist and removes content-bearing events; every normalizer runs it on every span it emits.

internal/codex stateful

Reconstructs one canonical trace per user turn from structured Codex logs

  • codingAgentConnector — connector.go; ConsumeLogs entrypoint, mutex-guarded turns map[string]*turnState, background sweepLoop ticker; Shutdown drains all active turns with finish reason “shutdown”.
  • turnState — event slice, seen-fingerprint set, first/last/lastSeen timestamps, completeSeen/completionAt, promptSeen, truncated flag.
  • parseEvent (event.go) — claims records whose event.name starts codex. and carries conversation.id; strips prompt/arguments/output before retention.
  • fingerprint() — sha256 over name, timestamp, attributes; dedupes at-least-once redelivery inside a live turn so token usage is not double-counted.
  • buildTrace (trace.go) — deterministic IDs: traceID = sha256(conversationID + prompt timestamp). One chat span per turn-completion response.completed, execute_tool spans per tool_result joined by call_id, remaining events as root span events. Re-emitting a finalized turn reproduces identical IDs.
  • Bounds and finalization — codex.max_active_turns LRU eviction, codex.max_events_per_turn truncation flag; reasons: completed, superseded, timeout, shutdown, evicted.
  • telemetry (metrics.go) — coding_agent.active_turns gauge (provider=codex) plus emitted/dropped/truncated counters.

internal/cursor stateful

Correlates native Cursor logs into activity-burst traces (Enterprise beta wire; no live e2e stack)

  • cursorConnector — connector.go; same lifecycle shape as codex: bursts map, sweep loop, flushAll on Shutdown.
  • burstState — event slice plus seen set keyed exactly on cursor.event.id; same bounds as turnState.
  • ParseRecord (event.go) — claims the cursor.telemetry scope when a conversation id is present; declines codex-named records.
  • buildTrace (trace.go) — root invoke_agent cursor spanning the burst; one point chat span per api_request (no durations invented); cache token rollups; api_error / api_correction join chat spans via cursor.usage_event.id; unmatched records become root events. Attribute policy is an allowlist, so canonical output stays content-free.
  • Finalization — quiet (normal close), timeout measured from burst start (error status), shutdown, evicted. Clock semantics differ from codex (inactivity-based) because Cursor has no completion event on the wire.

internal/claude · claudelogs · codextraces stateless

Harnesses with a second signal; config picks which one feeds canonical output

  • claude.NewWithChatSource (normalizer.go) — detected by span-name prefix; renames interaction / llm_request / tool spans; other spans keep native names; maps session.id to gen_ai.conversation.id; dangling parents stay intact so backends can reassemble across batches. Under chat_source: logs it drops claude_code.llm_request.
  • claudelogs (edge.go) — claims scope com.anthropic.claude_code.events; under chat_source: logs it turns each api_request / api_error record into one canonical chat span. The logs wire is the only Claude Code surface with per-request cost and API failures. No turn state, so replays are idempotent; consumes nothing under the default traces.
  • codextraces (normalizer.go) — Codex native spans from otel.trace_exporter; claims groups whose scope equals service.name and holds a Codex marker. Keeps session_task.turn/compact/review (→ invoke_agent roots), the usage-bearing response span, and tool spans; drops the rest and rebuilds every kept span's attributes from scratch.

internal/genai · opencode · pi · openhands stateless

Traces-to-traces normalization; copies pdata before modifying

  • genai — claims by scope-name prefixes (openai_v2, util.genai, strands.telemetry, github.copilot) after ownedElsewhere (claude, opencode, pi, openhands Claimers) declines the group. Name table rewrites only when the subject is present: chat {model}, invoke_agent {agent}, execute_tool {tool}; Copilot's agent subject varies by producer (copilot-cli / copilotcli).
  • opencode — exact-scope claim (opencode); filter-and-rebuild: ai.streamText/doStream/toolCall spans become one invoke_agent opencode per model step with chat children; internal instrumentation spans dropped.
  • pi — scope or telemetry.sdk.name prefix claim; reparents orphaned chat/tool spans onto invoke_agent pi roots within the batch; exporter-local Langfuse baggage and raw usage blobs never reach canonical output.
  • openhands — scope lmnr.tracer is shared by every Laminar app, so a group also needs an OpenHands conversation/agent span name or the is_delegate flag. Emits an invoke_agent root with reparented chat and execute_tool children; folds wrapper usage onto chat spans, dedupes call/result tool pairs by tool_call_id, remaps cost to coding_agent.usage.cost.
  • Attribute work — legacy token-key mapping (prompt/completion → input/output), gen_ai.system fallback for provider, provenance attributes, then content.Strip.
  • Copy-on-write — every router and edge reports MutatesData:false and copies before modifying, so Collector fan-out stays safe.

distribution + deployment files packaging

What turns the component into a running Collector

  • builder-config.yaml — pins OCB v0.163.0; otlp receiver; batch, resource, and deltatocumulative processors; otlp/debug/awss3/file/prometheusremotewrite exporters; file_storage + healthcheck extensions; this connector.
  • Dockerfile — two-stage build; OCB generates the dist main package, ships a single binary plus bundled config; EXPOSE 4317 / 4318 / 13133.
  • collector-config.yaml — e2e shape: three pipelines (logs/vendor, traces/native, traces/canonical) with file exporters; resource/e2e stamps e2e.run.id and re-stamps it after the connector, whose resource contract strips it. Sets codex.signals: [logs, traces] so the Codex stack exercises both edges.
  • compose.e2e-*.yaml — eight opt-in paid live stacks (claude, codex, copilot, openai, opencode, openhands, pi, strands) sharing the collector via include of compose.e2e-base.yaml, plus a zero-cost routing stack that replays fixtures through a two-tier consistent-hash gateway.
  • examples/ — otelcol-s3.yaml (one S3 prefix per stream, persistent sending queues on file_storage with fsync); otelcol-metrics.yaml (delta→cumulative before Prometheus remote write, per-replica series); k8s-ha/ (two-tier HA on Kubernetes: tier 1 routes stateful Codex/Cursor logs by conversation id and everything else by trace id).
  • State contract — correlation state is memory-only; exporter queues persist completed batches but not active turns. See docs/multi-instance-ha.md for the N-instance analysis.

Canonical output

invoke_agent <agent>          root span, one per user turn / activity burst / model step
├── chat <model>             one per model call (per api_request for Cursor and claudelogs)
└── execute_tool <tool>      tool spans; absent on the Cursor wire
finish_reasonEdgeMeaningStatus
completedcodex (logs)reorder window quiet after a completion eventunset
quietcursorno new record for the reorder window (normal close)unset
supersededcodex (logs)a newer prompt arrived for the conversationunset
timeoutbothno completion (codex) or overlong burst (cursor)error
shutdownbothcollector drain on graceful shutdownunset
evictedbothLRU eviction past max_active_turnsunset

Only the two stateful edges synthesize a root finish_reason; stateless edges carry the wire's span status (the Claude edge also lifts a child's error status onto its parent).
